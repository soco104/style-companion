# Style Companion Mobile

Expo React Native app placeholder for iOS and Android.

## MVP Screens

- Welcome
- Sign up / login
- Role selection
- Customer style quiz
- Customer profile
- Shopper profile creation
- Shopper match list
- Shopper detail
- Booking request
- Booking status
- Chat placeholder
- Review
- Account/settings

## API Mode

Mock mode is enabled by default. To point the app at the NestJS backend, set:

```bash
EXPO_PUBLIC_API_MODE=backend
EXPO_PUBLIC_API_URL=http://localhost:3000
```
