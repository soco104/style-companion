# Style Companion Admin

Next.js admin portal for internal marketplace operations.

## Pages

- Dashboard
- Users
- Shopper profiles
- Bookings
- Reviews moderation
- Safety reports

## Backend API

The portal reads and updates data through the NestJS API. Set `API_URL` if the API is not running at the default:

```bash
API_URL=http://localhost:3000
```

When running the admin and API locally, put one of them on a different port.
